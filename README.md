# SQL Quest

Aplicação interativa para aprender SQL: teoria + esquema visual + editor + validação automática. 5 lições em 3 trilhas.

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py     # abre em http://localhost:8501
pytest                   # valida gabaritos, validador e sandbox
```
